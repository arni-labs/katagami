# Prompt-only contribution contract

Native Temper ArtStyles.SubmitArtStyle is the contribution boundary. Contributors upload immutable Files and submit a complete draft; the finalizer verifies and publishes. Stack owns the single procedural skill; Katagami owns schema documentation and validators.

Gallery: six distinct outputs, four requested GPT Image 2.5, one Grok Image, one Nano Banana. Built-in output can honestly report an unexposed model ID; requested and actual model identity remain separate. Provider invocations retain exact IDs and request receipts. Every output binds immutable bytes and the actual text prompt. No image input is allowed for a prompt-only record.

Portability: one or two distinct subject descriptions, each generated by two distinct model identities using the same canonical prompt and subject. A source image or edit output cannot satisfy this contract. Unknown model versions cannot be presented as exact versions or counted twice as distinct models for one provider. Independent semantic review remains separate from artifact integrity validation.

Existing published styles remain visible. New submissions use gallery manifest3, proof manifest4, generation record2 and portability report2. Deploy actual modules, metadata and skill references; verify installed behavior rather than assuming a merged GitHub change is live.
