# ARN-475 — Encyclopedia exploration

Improve the existing encyclopedia at `/encyclopedia` so a large real collection remains fast, informative, and usable on desktop and mobile. Preserve the original agent’s UI and features. The user requested a reset to master, then prioritized gesture ownership, compact controls, visual category entries, explicit branch expansion, clear close-up cards, representative imagery, and readable connections before another feedback round.

The current deliverable is a verified local preview against the production backend, followed by user feedback. Full 3D and rotation remain exploratory ideas. See feedback.md for the complete conversation brief.
