# Interaction sketches

## A. Semantic map

Overview: [Art] — [Writing] / [Palettes] — [Design]

Zoom: [group count] → [topic name + child count] → [specimen card]

Expand: Encyclopedia / Art / Topic → [child] [child] [example]

The reader pans a stable field, enters one branch, and returns by breadcrumbs. Reading and expanding are separate actions. Spatial tiles aggregate unreadable nodes at distant zoom.

## B. Orbiting graph

Overview: a sphere of topic clusters. Drag rotates the sphere; pinch moves the camera. Selecting rotates a node forward and fans its children out behind it. Reading requires the card to face the camera.

Orbit allows rotation, but adds occlusion and makes drag ambiguous on phones. There is no attested third spatial axis in the source data.

## Selection

Use A: a 2D semantic map with canvas connectors, virtualized HTML cards, and arithmetic tile aggregation. Depth is conveyed by hierarchy and card elevation. This preserves readable content, touch gestures, and keyboard navigation without a 3D engine.
