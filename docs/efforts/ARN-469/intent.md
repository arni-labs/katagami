# Autoformalized design-language experiment

Test whether an agent can infer a useful design-language definition from existing materials, and whether formal reasoning improves creative image mockups while preserving perceived identity.

The user selected Galley and the current approved Impeccable Aya language. Use built-in image generation without additional model APIs. The user will review a short calibration set and a blind final comparison. Keep Impeccable unchanged.

Compare prose guidance, executable checking, and solver-backed construction or verified transformations. Report formal correctness, language inference, perceived identity, creativity, and craft separately. Run this as offline research. Production changes are outside its scope.
