Code styles in your own page

One script tag, then one element per piece. Each piece draws itself when it loads.

<script type="module" src="https://katagami.ai/code-styles/runtime/element.js"></script>
<katagami-draw style="kirie" subject="cat" seed="3"></katagami-draw>
<katagami-draw style="kirie" text="hello" params='{"backing":"#e2462f"}'></katagami-draw>
